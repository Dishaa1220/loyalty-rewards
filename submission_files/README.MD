# Customer Loyalty Rewards System

A reward system for a factory that sells products in boxes. Every box carries
a unique QR code. Customers scan it after buying to earn coins, and coins
convert to Indian rupees. The factory owner manages products, generates code
batches, and monitors redemptions from an admin dashboard.

# Tech Stack
- PHP 8+ (plain PHP, no framework)
- MySQL (via phpMyAdmin)
- Bootstrap 5
- XAMPP for local development

# Setup and Run
(To be completed as the project is built.)

1. Clone the repository into `C:\xampp\htdocs\`
2. Start Apache and MySQL in XAMPP
3. Copy `.env.example` to `.env` and fill in your values
4. Import `database/schema.sql` in phpMyAdmin
